# 🎬 CineHub

CineHub é uma aplicação web desenvolvida com HTML, CSS e JavaScript que permite visualizar e cadastrar filmes em um catálogo interativo.
 
O projeto foi criado como atividade da disciplina **Programação Web 1**, com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end, incluindo manipulação do DOM, eventos, formulários e validações utilizando JavaScript puro.

## 🚀 Funcionalidades
- Exibição de filmes em formato de cards
- Cadastro de novos filmes através de um formulário em modal
- Pesquisa de filmes por título
- Exibição de informações do filme:
- Imagem
- Título
- Categoria
- Ano de lançamento
- Validação de campos obrigatórios
- Atualização dinâmica do catálogo sem recarregar a página

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## 📋 Como Utilizar
1. Clone este repositório:
 
```bash
git clone https://github.com/seu-usuario/cinehub.git
```
 
2. Acesse a pasta do projeto:
 
```bash

```

3. Abra o arquivo `index.html` no navegador.
